Before you start

Put the DX7 engine on your FM-1 and try itAbout 20 minutes. Nothing here is permanent: SLOOP 2.3 is one install away, and your projects, presets, samples and settings are kept throughout.

You need

  • Chrome or Edge on this laptop (they have Web MIDI)
  • a USB data cable, FM-1 plugged directly, no hub
  • the FM-1 switched on, running SLOOP
  • no other MIDI app or editor tab open

Rule for the whole test

Every flash write (install, loading voices, restore) wants the song stopped. If a screen says STOP BEFORE SAVE, press PLAY to stop and do it again.

Step 1 of 4 · install

Back up first

  1. Open the installer page below.
  2. Click Editor on that page, press Connect, allow MIDI.
  3. Tab Projects → Save a backup. A SLOOP-backup-….json downloads. Keep it.
Open the installer page

You should see

The editor's status line says Backup saved. That file brings everything back if you ever want to.

Step 2 of 4 · install

Install the test build

  1. Back on the installer page, press INSTALL.
  2. Wait for Done. The FM-1 restarts on the SLOOP logo (about a minute).
  3. On the FM-1: hold HOME → ABOUT.

You should see

2.4-DX7 BETA

Your tracks, sounds and projects are exactly as before. Unplug and replug the USB cable once so the computer finds the FM-1 again.

If the installer does not find the FM-1

Data cable, no hub, close other MIDI apps, reload the page. An install that stopped half-way: press INSTALL again, it finishes.

Step 3 of 4 · the voices

Download the four factory voice files

The FM-1's own 128 factory sounds as standard DX7 banks, 4,104 bytes each (checked: header and Yamaha checksum). If the browser shows a file instead of saving it, right-click → Save link as.

FM-1_factory_bank1.syx — PIANO · ORGAN · SYN LEAD · SYN PAD FM-1_factory_bank2.syx — GUITAR · DS GUITAR · BASS · SYN BASS FM-1_factory_bank3.syx — BRASS · WOODWIND · STRING · VOICE FM-1_factory_bank4.syx — bells, drums, effects

Any other DX7 .syx works the same way later: a 32-voice bank, or a single voice of 163 bytes.

Step 4 of 4 · the voices

Load them into the FM-1

  1. Editor → Connect → tab Library. The DX7 voices group is on the right.
  2. Dropdown Bank 1 → Load .syx → pick FM-1_factory_bank1.syx.
  3. Same for Bank 2, 3, 4 with the other three files.
Open the editor

You should see

The 32 names appear under the bank (32 / 32 used), the status line says Written to the FM-1. Each bank takes a second or two.

Test 1 · browse

The voices are in PRESETS, by name

  1. On the FM-1 pick track 1 (ALGORITHM knob).
  2. Turn PRESETS forward past SLOOP's 68 sounds.
  3. Stop on PIANO 1 and play the keys.

You should see

The list continues with the DX7 voices, each tagged with its bank DX1 … DX4, then your user presets. The header shows the voice's name.

Faster: jump by kind

Tap SAVE → the PRESETS page. KNOB 1 one sound, KNOB 2 the engine, KNOB 3 (KIND) jumps: basses → keys → … → FX → DX1 → DX2 → DX3 → DX4 → user presets, and back. HOME knob 1 steps through the 128 slots by number.

Test 2 · play

Chords, and two DX7 tracks at once

  1. Hold a chord on PIANO 1. Try ORGAN 1, BRASS 1, SYN PAD 1, TUB BELLS, KALIMBA.
  2. Put a DX7 voice on track 2 too, record a pad there, play a lead on track 1 over it.
  3. Add the drum track as usual.

You should hear

Eight voices shared across the tracks, as with every SLOOP engine; on a dense part the oldest extra note fades out, never the bass or the lead. No clicks, no stuck notes after releasing everything.

Test 3 · knobs

The four HOME knobs on a DX7 track

PTCHthe voice, 001–128
BRGTdarker ← → brighter
ENVSenvelopes slower ← → faster
RELrelease of the ADSR in front

Tap EDIT: page PATCH is PTCH · BRGT · ENVS · LFOD (more or less pitch LFO); page TONE is TRN transpose in semitones · ALG and FB override the voice's algorithm and feedback (0 = the voice's own) · one empty column, as other SLOOP engines have.

You should find

ENV, LFO, FX, ARP, SCL, chords and the sequencer behave exactly as on any other engine. BRGT is the one to turn first: it is the classic DX7 brightness control.

Test 4 · editor

Play from the editor, export a bank

  1. Library → DX7 voices → double-click a voice (or select it and press Play on this track).
  2. Press Export .syx on a bank.

You should see

The selected track switches to that voice at once (the track must run the DX7 engine, else the status says so). A SLOOP-DX7-bank1-….syx file downloads: a normal DX7 bank, openable in Dexed.

Reload button

Re-reads the four banks from the FM-1. Use it after sending anything from Dexed.

Test 5 · power cycle

A project remembers its voice

  1. With a DX7 voice on track 1, save the project (SAVE → PROJECT → SAVE, as usual).
  2. Switch the FM-1 off, then on.

You should see

It comes back on the same voice, same name in the header, the sequence intact. (A project stores which slot the track plays; the voices themselves live in the four banks in flash.)

Test 6 · backup

The banks are part of a backup

  1. Editor → Projects → Save a backup (a new file, now with the voices in it).
  2. Library → DX7 voices → Bank 4 → Erase bank, confirm. The 32 names go.
  3. Projects → Restore from a file → the backup you just made.

You should see

After the restore, Bank 4 lists its 32 voices again (press Reload if the list is stale). The FM-1 must be stopped for a restore.

Test 7 · Dexed (optional)

Straight from Dexed, like a DX7

  1. On the FM-1 select a DX7 track and stop playback. In Dexed, set the MIDI out to the FM-1.
  2. One voice: Dexed → Send current program.
  3. A bank: Dexed → Send bank.

You should see

One voice: DX7 017 E.PIANO 1 style message and the track plays it (it replaced the slot the track was on). A bank: DX7 BANK 1? SAVE=YES — press SAVE to write it, anything else cancels. Nothing else opens when you answer.

While playing

STOP BEFORE SAVE — stop, resend.

Test 8 · going back and forward

SLOOP 2.3 must still open everything

  1. Install SLOOP 2.3 from its own page (link below). Load the project from test 5.
  2. Then install the test build again from the first link.
SLOOP 2.3 installer Test build installer

You should see

On 2.3 the project opens with the DX7 track on ANALOG and nothing else lost (no DX7 engine there, so that is the expected fallback). Back on the test build, the four banks are still full without reloading: an install never touches the stored data.
